AI Usage（以下「本アプリ」）は、macOS と Windows 向けのデスクトップユーティリティです。macOS ではメニューバー、Windows では小さなフローティングウィンドウに、Cursor、ChatGPT（Codex）、Claude Code などの使用量を表示します。本ポリシーは、両 OS 版における情報の取り扱いについて説明します。

開発者が収集する情報

本アプリは、使用履歴、プロンプト、ソースコード、認証情報、端末識別子、診断ログなどをスタジオとみっぺのサーバーへ自動送信しません。広告 SDK や利用状況の分析 SDK も使用しません。

使用量の取得に必要な認証情報と使用量データは、お使いの端末上で処理します。Cursor と Anthropic には本アプリまたは Claude Code から、OpenAI にはインストール済みの Codex CLI を介して使用量を問い合わせます。認証情報やアカウント情報は、使用量を返す各サービスに送られます。各サービス側の取り扱いは、そのサービスの利用規約とプライバシーポリシーに従います。

端末上で読み取る情報

本アプリは、インストール済みプロバイダの使用量を表示するため、次の情報を端末上で読み取ります。

  • Cursor：Cursor のローカルデータベースに保存された認証トークンやアカウント識別情報を読み、Cursor の使用量 API に問い合わせます。トークンとアカウント識別情報は Cursor のサービスに送られます。
  • ChatGPT（Codex）：端末にインストールされた Codex CLI / ChatGPT の認証状態を使い、Codex のローカル app-server に使用量上限を問い合わせます。認証情報を扱うのは Codex 側で、本アプリが認証情報を開発者へ送ることはありません。
  • Claude Code：macOS 版は Claude Code のローカル認証情報を使って Anthropic の使用量 API に問い合わせます。Windows 版は Claude Code の statusline 連携から使用率とリセット時刻を受け取ります。連携用の設定が未登録で既存の statusline 設定もない場合、本アプリは Claude Code の設定に連携を追加します。連携では statusline の入力全体を一時的に読み取りますが、保存するのは使用率とリセット時刻だけで、プロンプトや作業パスなどは保存しません。

外部サービスとの通信

  • Cursor、OpenAI（Codex）、Anthropic（Claude Code）：使用量を取得するため、各サービスの API または公式クライアントへ問い合わせます。Cursor の認証トークンやアカウント識別情報、各サービスで認証された状態が、それぞれのサービスに送られます。
  • Frankfurter：USD 以外の通貨を選択した場合に、換算レートを取得するため、選択通貨コードを含むリクエストを送信します。取得したレートは端末内に最長 6 時間キャッシュします。
  • 更新確認：macOS 版は配布サーバー（apps.tomippe.jp）から更新情報を確認します。Windows 版の更新メニューは Microsoft Store または GitHub Releases をブラウザで開きます。接続先は通信に伴い、IP アドレスやアクセス時刻などの通常の通信記録を扱う場合があります。
  • フィードバック：メニューから選択した場合、ブラウザで Airtable のフォームを開きます。フォーム URL にはアプリ名、アプリのバージョン、OS 情報が含まれ、Airtable に送信されます。ユーザーがフォームから送信した内容とメールアドレス（任意）は運営者に届きます。

端末内での保存

表示設定、選択通貨、音声アラート設定、ウィンドウ位置、為替レートのキャッシュは端末内に保存します。macOS 版は macOS の設定領域を使い、Windows 版はユーザープロファイル内の設定ファイルを使います。ログイン時に起動する設定を有効にした場合、macOS のログイン項目または Windows のユーザー設定に登録します。

Claude Code 連携の使用量スナップショットは、ユーザープロファイル内の .claude フォルダに保存します。連携を本アプリが追加した場合、Claude Code の設定ファイルに statusline の登録が残ることがあります。これらの設定・ファイルは本アプリのアンインストール時に自動削除されない場合があります。

第三者への情報提供

本アプリは使用履歴や認証情報を運営者へ送信しません。使用量の問い合わせ先となる各サービスおよび、ユーザーが送信したフィードバックを処理する Airtable での情報の取り扱いは、それぞれのサービスのポリシーに従います。
